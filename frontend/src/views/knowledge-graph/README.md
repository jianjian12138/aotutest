# 知识图谱功能说明

知识图谱功能基于Vanna AI实现，需要配置大模型才能正常使用全部功能。

## 配置步骤

1. 进入**数据工厂**模块
2. 点击**配置管理**
3. 创建或编辑Vanna AI配置
4. 填写以下信息：
   - 配置名称：任意名称
   - AI提供商：建议使用openai
   - AI模型：建议使用gpt-4o
   - API密钥：您的OpenAI API密钥
   - 数据库类型：mysql
   - 数据库连接配置：根据实际情况填写

## 功能说明

1. **多模态文档管理**：支持上传PDF、Word、Markdown、图片等多种格式的文档
2. **智能搜索**：基于RAG技术的语义搜索，支持多维度检索和智能问答
3. **知识图谱可视化**：自动生成知识图谱，可视化展示实体关系和知识关联

## 注意事项

- 知识图谱功能需要配置有效的大模型API密钥
- 上传的文档会被处理并生成知识图谱
- 智能搜索和知识图谱可视化功能依赖大模型
