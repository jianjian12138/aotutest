## 统一页面UI风格修改计划

### 分析当前状态
通过分析【数据工厂】下【配置管理】页面和【API测试】下【项目管理】页面的代码结构，发现两个页面的风格基本相似，但存在一些细微差异，需要统一。

### 统一风格要素
根据【数据工厂】配置管理页面的风格，制定以下统一标准：

#### 1. 页面布局
- 使用 `el-card` 作为页面容器，设置 `shadow="hover"`
- 卡片标题区域使用 flex 布局，实现标题与操作按钮的左右对齐
- 内容区域设置 `padding: 20px 0`

#### 2. 标题样式
- 标题字体大小：20px
- 字体权重：600
- 颜色：使用 Element Plus 默认标题颜色

#### 3. 搜索过滤区域
- 使用 flex 布局，组件间距：16px
- 底部 margin：20px
- 搜索输入框宽度：300px
- 过滤选择器宽度：180px

#### 4. 表格样式
- 启用边框：`border`
- 启用条纹效果：`stripe`
- 统一列宽设置

#### 5. 分页区域
- 使用 flex 布局，右对齐
- 顶部 margin：20px

#### 6. 按钮样式
- 主操作按钮使用 `type="primary"`
- 编辑/查看按钮使用默认样式
- 删除按钮使用 `type="danger"`
- 状态切换按钮根据状态使用不同类型
- 按钮大小统一使用默认大小，操作列按钮使用 `size="small"`

#### 7. 对话框样式
- 统一对话框宽度：60%
- 表单标签宽度：120px
- 内容布局对齐

### 修改方法
1. **创建统一的样式文件**：
   - 在 `src/assets/css` 目录下创建 `unified-styles.scss`
   - 定义统一的页面布局、标题、搜索区域、表格和分页样式

2. **修改各页面组件**：
   - 导入统一的样式文件
   - 调整页面布局结构，确保与数据工厂配置管理页面一致
   - 修改按钮样式，统一使用标准按钮类型
   - 调整表单和对话框样式

3. **验证修改效果**：
   - 逐一检查每个修改后的页面，确保风格一致
   - 验证功能正常，无样式冲突

### 预期效果
- 所有页面采用统一的布局和样式
- 标题、按钮、表格等元素风格一致
- 页面间距、字体大小等视觉要素统一
- 整体视觉效果协调，提升用户体验
